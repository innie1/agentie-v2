# Agentie v2

A clean Python-first rebuild of Agentie using FastAPI and the OpenAI Agents SDK, with support for OpenAI-compatible model providers such as OpenRouter.

## Phase 1

- One Agentie assistant
- OpenRouter-compatible model layer
- Python function tools
- FastAPI API
- Health check endpoint

More capabilities such as Supabase memory, approvals, skills, plugins, handoffs, and sandboxed computer tools will be added incrementally.
